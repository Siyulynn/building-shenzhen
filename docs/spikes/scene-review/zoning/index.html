Core basin design maps (1979 & January 1984) / 深圳核心区基准设计图（1979 与 1984 年 1 月）

Authoritative 100 m game-grid design maps for both the 1984 3D atlas and the in-game reference plan. Built blocks, active graded earthworks, civic/park grounds and transport yards explicitly replace 1980 KH-9 farmland, while unzoned lowland remains preserved farmland.

两图采用统一的百米游戏网格，作为 1984 年三维场景与游戏参考规划的基准设计图。明确区分已建街块、平整施工工地、机关公园与站场口岸（在三维场景中替代 1980 年 KH-9 农田底图）以及保留农田范围。
